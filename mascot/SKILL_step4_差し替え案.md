## 置き換え後の記述

### X・Instagram共通:マスコットは「承認済みライブラリ」から選ぶ

**投稿ごとのAI画像生成は行わない。** 事前に生成し、田島さんが目視で合格判定した画像だけを収めた
ライブラリから、投稿の切り口に合うものを選んで使う。

- ライブラリの実体:`sterlingaxiom-sns-assets/mascot/approved/` と `mascot/manifest.json`
- 選択方法:`select_mascot.py` を使う。投稿の切り口を `--use` に渡すと、承認済み画像から
  1枚を選び、GitHubの公開raw URLを返す

```bash
python3 select_mascot.py --use 危機喚起型
python3 select_mascot.py --use ランキング型 --framing full   # 脇役配置には full が向く
```

- `--use` に渡す値:`成長訴求型` / `危機喚起型` / `ランキング型` / `ハウツー型` / `説明` / `汎用`
- 直近8件で使った画像は自動的に避けられるため、同じ絵の連続は起きない
- 該当する切り口の在庫が無い場合は `汎用` に自動フォールバックする。**在庫不足を理由に
  処理を止めてはいけない**
- 文字(数字・キーフレーズ)を重ねる場合は、従来どおり **HTML+CSS でレイアウトして
  ヘッドレスブラウザでPNG化**する。マスコット画像はその中に `<img>` として配置する。
  AI画像生成側に文字を描かせないという原則は変わらない

### この方式にした理由(記録)

従来の「毎回生成 + 最低10回リトライ」方式には以下の問題があった。

- 実行時間が読めない(リトライ回数次第)
- 生成品質が実行ごとにブレる
- クラウド実行環境のネットワーク設定によっては Pollinations に到達できず、画像なしになる
- 品質判定をClaude自身に任せており、人の目より甘くなる余地があった

事前生成ライブラリ方式は、これらをすべて解消する。品質の担保は
**「田島さんが一度、目視で選別する」**という形で人の側に置かれる。
